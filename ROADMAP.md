## Design Principles (Always)

Throughout all phases, we maintain:

1. **Simplicity First**
   - Every feature must justify existence
   - One clear path for every action
   - No unnecessary complexity

2. **Black & White**
   - 5 color values only
   - No gradients, no decoration
   - Timeless aesthetic

3. **Keyboard-First**
   - Every action has shortcut
   - Power users never need mouse
   - Command palette for everything

4. **Invisible AI**
   - Intelligence that supports
   - Never interrupts
   - Always optional

5. **Local-First**
   - Fast by default
   - Works offline
   - Syncs automatically

6. **Real-time Native**
   - Multiplayer everywhere
   - Live updates
   - Presence awareness
